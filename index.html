Architecture & Specs

为什么 NovaPlayer 如此轻快？

我们拒绝臃肿的第三方广告 SDK 和冗余框架，采用 C 级直通流代理与 Flutter 现代化渲染管线。

Questions & Answers

常见问题解答

支持哪些局域网与云存储设备？

完美支持所有主流家庭 NAS 设备（群晖 Synology、威联通 QNAP、绿联、极空间等）、Windows 电脑本地共享文件夹、Linux Samba 服务器，以及任何标准 WebDAV 服务器和 AList 挂载源（可无缝接入百度网盘、阿里云盘、115 网盘、夸克网盘等）。

安装 APK 时手机提示“报毒 / 未知来源”怎么办？

NovaPlayer 为个人独立精心自研，承诺绝无任何恶意后门、吸费或侵权行为。部分国产手机（华为、小米、OPPO、vivo 等）会对未上架其官方商城的 APK 弹出常规安全拦截提示，在安装时勾选“已知晓风险，继续安装”即可放心使用。

会推出 iOS 或 Android TV 电视版吗？

NovaPlayer 基于 Flutter 跨平台架构开发，核心媒体引擎具备极佳的可移植性。目前我们正全力完善安卓移动端与平板体验，TV 遥控器大屏交互与更多平台版本已在未来规划日程中，欢迎关注我们的 GitHub 仓库动态！
